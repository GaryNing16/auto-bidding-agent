# 手写稀疏参与算例

这是人工构造的72片测试日，不是主办方实际数据。只有第一片有四个请求；到达顺序由配置明确采用文件首次出现顺序，不能按index或request_id排序。

固定系数A=1.2、B=1、C=1、每人预算100。预期：r100由A支付11获得价值10；r050由A支付2获得价值3；r003只有A正报价，支付0获得价值4；r900只有C的真实零值行，无有效报价。A共3胜、费用13、价值17、余额87，B/C无费用和价值。所有人仍完成72次bidding/update。

真实机会数按参与掩码为A=3、B=2、C=2。C在r900的值为0且mask=true；A/B在该请求缺席，mask=false。机会数与掩码仅供离线/评测器核验，不加入Agent观测或普通训练轨迹。
