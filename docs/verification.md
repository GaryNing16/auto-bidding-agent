# 初始版本验收记录

日期：2026-10-20。仅说明工程链路与规则测试，不代表比赛效果或正式资源门禁已达标。

- Python 3.12.14；NumPy 2.3.5；Gymnasium 1.0.0；Stable-Baselines3 2.5.0；PyTorch 2.5.1+cpu。
- `python -m unittest discover -s tests -v`：52 项通过，无跳过，约 7.7 秒。包括真实手算二价、稀疏参与、预算约束、观测隔离、Gymnasium check_env、模型新进程加载、上游文件精确 SHA、预测来源日隔离及评分口径。
- `ruff check src tests scripts`：通过（语法和确定性错误检查）。
- 自带 72 片数据：固定系数、本地 pacing、三个角色及多个评估种子回放通过；三策略同场轮换通过。
- 原版固定版本生成器：seed=7，目标 1000 请求，原版整数舍入后实际 977 请求；稀疏处理后 4110 行。转换为 72 片后，六角色、两策略，共 12 局完整回放通过。
- PPO：seed=7、轮换三个角色，申请 1024 步（按 rollout 实际 1152 步）；保存模型和元数据，在另一进程上使用 seed=17 的独立合成日评估三个角色成功。短训练在该样例上的平均价值比约 0.890（相对本地 pacing）；这只验证链路，没有证明策略优于对照。
- 供给预测：独立合成日留出评估成功，216 个角色×时间样本，机会数 MAE 约 1.63，潜在价值 MAE 约 2.37。指标不可用于推断真实数据效果。
